# Open Alienware Command Center

Лёгкая портативная замена Alienware Command Center для Alienware m18 R2. Без телеметрии и лишних служб — один exe.

## Возможности

- Подсветка клавиатуры по клавишам, эмблема и контур, яркость, свои схемы.
- Обычные эффекты клавиатуры (дыхание, спектр, волна, сканер) и эффекты «На нажатия».
- Второй цвет цифрового блока при выключенном Num Lock.
- Значки Fn Lock и тачпада прямо на клавиатуре в окне.
- Правый клик по HOME / END / DEL меняет их функции местами.
- Режимы питания Dell: Энергосбережение, Тихий, Баланс, Производительность, Максимум.
- Температуры, загрузка и вентиляторы, график за 2 минуты.
- Значок батареи в трее с переключением режимов.
- Автозапуск вместе с Windows.

## Запуск

Скачай exe из раздела Releases и запусти. Установка не нужна, настройки хранятся в файле рядом с exe.

## Сборка

```
$env:RUSTFLAGS='-C target-feature=+crt-static'
cargo build --release
```
